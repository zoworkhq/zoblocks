# Changelog

Per-package changelogs are generated by [Changesets](https://github.com/changesets/changesets)
and live beside each package:

- [`@oxygenui-design/loaders`](packages/loaders/CHANGELOG.md)
- [`@oxygenui-design/tokens`](packages/tokens/CHANGELOG.md)
- [`@oxygenui-design/fhir`](packages/fhir/CHANGELOG.md)

This file records changes to the **repository** — architecture, tooling,
standards, and process — that no single package owns.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versioning follows [semantic versioning](https://semver.org), with the
stability tiers and breaking-change rules in
[ENGINEERING.md §13](ENGINEERING.md).

## [Unreleased]

### Added

- `ENGINEERING.md` — the standard every component, fix, and release is
  evaluated against, opening with a one-page definition of done.
- Governance set: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`,
  `SUPPORT.md`, `CODEOWNERS`, a pull-request template, and issue templates for
  bugs, accessibility, and component requests.
- Supply chain: Dependabot with grouped updates, CodeQL static analysis on a
  weekly schedule, and CycloneDX SBOM generation attached to every release.
- `pnpm audit --audit-level=high` as a gate in both CI and the release
  workflow.
- Coverage thresholds (90% lines and functions, 85% branches), enforced.
- A Node-environment test suite for `@oxygenui-design/loaders`, so a
  server-rendering regression fails the build.
- Tests for the token validator itself — contrast maths, published evidence,
  theme parity, and alias resolution.
- `check-tarball.mjs` for `@oxygenui-design/tokens`, the one publishable
  package that had no pre-publish inspection.

### Fixed

- **`@oxygenui-design/loaders` crashed on import in any Node context.**
  `class OxLoaderElement extends HTMLElement` was evaluated at module scope, so
  Nuxt, Angular Universal, Astro, SvelteKit, and Next.js server components all
  threw `ReferenceError` before rendering anything.
- **Three WCAG 2.2 AA contrast failures in the light palette.** The focus
  indicator measured 2.50:1 against a 3:1 requirement, `text-on-accent` 3.81:1
  against 4.5:1, and `border-strong` 1.48:1 against 3:1. The contrast gate has
  been widened from 4 pairs to every foreground the system composes, split by
  the WCAG rule that applies.
- **Props tables documented roughly one prop per component.** The extractor
  excluded anything not declared in the component's own file, which hid every
  prop on the shared interface. 3 extracted props became 105.
- **The docs deploy gate verified a component that had been deleted**, so the
  next merge to `main` would have failed. It now verifies the served registry
  against what the commit actually built.
- **Releases ran fewer gates than merges** — no lint, typecheck, format,
  generator drift check, or audit, and no dependency on CI passing.
- **Shipped npm source received none of Oxygen's own lint rules.** The ESLint
  globs named `packages/react/**` and `packages/pro-*/**`, neither of which
  exists.
- Command-injection sinks in two workflows, where free-form input was
  interpolated into a shell before parsing.
- Unresolved DTCG aliases leaking into `tokens.json`, which is documented as a
  flat map for external tooling.
- Published contrast floors disagreeing with the floors the gate enforces.
- Fork pull requests reporting a successful preview deployment that deployed
  nothing.
- One critical and five high dependency advisories.

### Changed

- Least-privilege `permissions` blocks on every workflow; concurrency
  cancellation no longer applies to `main`, where it could cancel a deploy
  mid-flight.
- The lint warning budget ratcheted from 35 to 8.
- `passWithNoTests` removed — deleting every component test no longer leaves
  CI green.
