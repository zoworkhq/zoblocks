# Bundle budgets

`.size-limit.json` is the enforced version of ENGINEERING.md §11.

The budget is on **installed bytes**, not repository size: a component library's
value proposition is what a customer ships to their users, and everything else
is our problem rather than theirs.

Limits sit just above today's measured size so they **ratchet rather than
aspire**. When a number here goes up, that is a decision someone made in a pull
request — which is the point. Lower them when you can; never raise one to make
a build pass.

React and react-dom are excluded from the React measurements because they are
peer dependencies the host already has.

## What the accordion's number is actually made of

`react — accordion` measures 9.74 kB, and roughly six of those are
**tailwind-merge**, reached through `cn` in `registry/oxygen/lib/utils.ts`.

The accordion uses no Tailwind utilities of its own — the header of
`accordion.css` states why, and the same is true of all five loaders. `twMerge`
therefore has nothing to merge: it is resolving conflicts between utility
classes that the component never emits. Plain `clsx` would produce identical
output for about a sixth of the bytes.

This is not fixed here, deliberately. `cn` is the house convention across the
whole catalog, and diverging in one component is how a convention rots — the
next author copies whichever neighbour they happened to open. It is a
catalog-wide change with a codemod behind it, or it is nothing.

Recorded rather than silently absorbed, because "why is a plain-CSS component
ten kilobytes" is the first question anyone reading this file will have.

`react — the headless behaviour layer` is the number to watch for the L1 claim:
**1.86 kB**, dependency-free, and it is where the accessibility correctness
lives. A customer who rebuilds the visuals keeps that and pays for nothing else.
