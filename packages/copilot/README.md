# @zoblocks/copilot

A floating clinical copilot for Ant Design. Model-agnostic, source-attributed, and designed so that checking the answer is cheaper than accepting it.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/copilot
```

Peer dependencies: `antd`, `react`, `react-dom`.

## Entry points

| Import                         | File                |
| ------------------------------ | ------------------- |
| `@zoblocks/copilot`            | `./dist/index.js`   |
| `@zoblocks/copilot/styles.css` | `./dist/styles.css` |

Documentation: https://zoblocks.design/components/copilot
