# @zoblocks/theme

Customer themes at runtime: the document model, the ramp generator, the three-point validation, and the CSS payload a published theme is served as.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/theme
```

Peer dependencies: `react` (optional).

## Entry points

| Import                  | File              |
| ----------------------- | ----------------- |
| `@zoblocks/theme`       | `./dist/index.js` |
| `@zoblocks/theme/react` | `./dist/react.js` |
| `@zoblocks/theme/logo`  | `./dist/logo.js`  |

Documentation: https://zoblocks.design
