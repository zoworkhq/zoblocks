# @zoblocks/recorder-core

The signal engine behind ZoBlocks's Recorder. A peak envelope with instant attack and a 180 ms release, 30 Hz peak buckets, and the eleven-phase capture machine with the consent edge enforced in the engine — no React, no DOM, no dependencies.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/recorder-core
```

| `@zoblocks/recorder-core` | `./dist/index.js` |
