# @zoblocks/copilot-evals

The eval harness behind ZoBlocks Copilot. Five suites and one release gate — because below roughly 70% reliability, automation makes clinicians worse than no automation.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/copilot-evals
```
