# @zoblocks/host-react

The host primitives an application is built from — Button, Input, Switch, Checkbox, Select, Tabs — resolved from whichever UI framework the host runs, so one demo source renders under Ant Design, Material UI, or neither.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/host-react
```

Peer dependencies: `@mui/material` (optional), `antd` (optional), `react`.

## Entry points

| Import                          | File              |
| ------------------------------- | ----------------- |
| `@zoblocks/host-react`          | `./dist/index.js` |
| `@zoblocks/host-react/antd`     | `./dist/antd.js`  |
| `@zoblocks/host-react/mui`      | `./dist/mui.js`   |
| `@zoblocks/host-react/host.css` | `./dist/host.css` |

Documentation: https://zoblocks.design
