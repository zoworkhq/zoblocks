# @zoblocks/copilot-core

The engine behind ZoBlocks's clinical copilot. Session state machine, provider contract, mode scope contracts, safety pipeline and FHIR audit mapping — no React, no DOM, no dependencies.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/copilot-core
```

## Entry points

| Import                   | File              |
| ------------------------ | ----------------- |
| `@zoblocks/copilot-core` | `./dist/index.js` |

Documentation: https://zoblocks.design/components/copilot
