# @zoblocks/bridge-mui

Theme bridge for Material UI: reads a host's resolved MUI theme and writes ZoBlocks's component token surface, so ZoBlocks components take the host's design language without importing MUI.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/bridge-mui
```

Peer dependencies: `@mui/material`, `react`.

## Entry points

| Import                            | File                |
| --------------------------------- | ------------------- |
| `@zoblocks/bridge-mui`            | `./dist/index.js`   |
| `@zoblocks/bridge-mui/definition` | `./dist/map.js`     |
| `@zoblocks/bridge-mui/inverse`    | `./dist/inverse.js` |

Documentation: https://zoblocks.design
