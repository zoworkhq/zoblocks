# @zoblocks/bridge-antd

Theme bridge for Ant Design: reads a host's resolved antd theme and writes ZoBlocks's component token surface, so ZoBlocks components take the host's design language without importing antd.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/bridge-antd
```

Peer dependencies: `antd`, `react`.

## Entry points

| Import                             | File                |
| ---------------------------------- | ------------------- |
| `@zoblocks/bridge-antd`            | `./dist/index.js`   |
| `@zoblocks/bridge-antd/definition` | `./dist/map.js`     |
| `@zoblocks/bridge-antd/inverse`    | `./dist/inverse.js` |

Documentation: https://zoblocks.design
