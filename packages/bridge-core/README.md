# @zoblocks/bridge-core

The theme-bridge contract: how a UI framework's resolved theme becomes ZoBlocks's component token surface. No framework, no React, no DOM.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/bridge-core
```

Peer dependencies: `react` (optional).

## Entry points

| Import                  | File              |
| ----------------------- | ----------------- |
| `@zoblocks/bridge-core` | `./dist/index.js` |
