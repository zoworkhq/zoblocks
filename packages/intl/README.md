# @zoblocks/intl

Messages and clinical register for ZoBlocks. Patient-facing and clinician-facing strings are different catalogs, not different tones.

Part of [ZoBlocks](https://zoblocks.design).

```bash
npm install @zoblocks/intl
```

Peer dependencies: `react`.

## Entry points

| Import           | File              |
| ---------------- | ----------------- |
| `@zoblocks/intl` | `./dist/index.js` |

Documentation: https://zoblocks.design
