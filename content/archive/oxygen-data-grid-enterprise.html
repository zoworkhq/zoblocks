Five worklist screens, not five tables.

The comparison is AG Grid inside myAvatar or CareFabric, so the bar is a working screen: saved views, filter state with counts, bulk selection, sortable headers with menus, a pinned identity column, grouping, density, pagination, export, master–detail. Every clinical claim the component makes is still load-bearing underneath — coverage, held arrivals, provenance on a derived sort, absence in words, 42 CFR Part 2 — expressed the way an application expresses things rather than the way a landing page does.

Functional chrome, not decorative

A cycling caption is decoration. A filter bar that says how many rows each predicate removed is the product. The earlier rounds cut both; this cuts only the first.

Density is a control, not a taste

A supervisor scanning 300 clients and a clinician working six need different row heights. 04 is the same grid at the power-user end of that control.

The safety claims survive the chrome

Coverage is a banner, provenance sits in the footer beside the sort, Part 2 is a flag and a word. None of it is decoration that a buyer can ask you to remove.
